# سعراتي — نسخة أندرويد (Capacitor)

بيحوّل تطبيق الويب (`calorie-app`) لتطبيق أندرويد حقيقي، وبيقرا **الخطوات تلقائي** من Health Connect.

> التجهيز ده اتكتب من غير ما يتجرب على جهاز فيه Android Studio، فاحتمال تحصل أخطاء في أول بناء. لو حصل، ابعت الرسالة كاملة.

## 1) على الجهاز الشخصي: تسطيب الأدوات (مرة واحدة)
1. **Node.js** (نسخة LTS، 22 أو أحدث): https://nodejs.org
2. **Android Studio**: https://developer.android.com/studio
   - افتحه مرة، ووافق على تسطيب Android SDK اللي بيعرضه في أول تشغيل.

## 2) نقل المشروع
انسخ المجلدين **جنب بعض** في نفس المكان:
```
Geem/
  calorie-app/        ← تطبيق الويب
  saraati-android/    ← المجلد ده
```

## 3) بناء ملف التجربة (APK)
افتح PowerShell داخل `saraati-android` ونفّذ:

```powershell
npm install
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
npm run apk
```

- أول مرة بياخد وقت (بيحمّل أدوات Gradle).
- لو Android Studio متسطب في مكان تاني، غيّر مسار `JAVA_HOME` لمجلد `jbr` جواه.
- لما يخلص هتلاقي الملف هنا:
  `android\app\build\outputs\apk\debug\app-debug.apk`

لو ظهر خطأ إن الـ SDK مش متحدد، اعمل ملف `android\local.properties` وحط فيه (غيّر اسم المستخدم):
```
sdk.dir=C\:\\Users\\<اسمك>\\AppData\\Local\\Android\\Sdk
```

## 4) التثبيت على الموبايل
1. انقل `app-debug.apk` للموبايل (كابل أو واتساب لنفسك أو درايف).
2. افتحه واسمح بالتثبيت من "مصادر غير معروفة" لما يطلب.
3. على أندرويد 13 أو أقدم: نزّل **Health Connect** من جوجل بلاي. (أندرويد 14 فأعلى بيجي معاه جاهز.)
4. افتح سعراتي. أول مرة هيطلب صلاحية **الخطوات** من Health Connect، وافق.
5. لازم يكون فيه تطبيق بيسجّل خطواتك على موبايلك وبيكتب في Health Connect (Google Fit أو Samsung Health) عشان تظهر أرقام.

شاشة اليوم هتعرض زرار **تحديث** جنب الخطوات، وبتتحدّث لوحدها لما ترجع للتطبيق.

## تحديث التطبيق بعد أي تعديل
عدّل في `calorie-app` وبعدين نفّذ:
```powershell
npm run apk
```

## ملاحظات
- **الخطوط:** خط Cairo بيتحمّل من الإنترنت، ولو مفيش نت بيستخدم خط النظام.
- **الأيقونة:** حاليا الأيقونة الافتراضية لـ Capacitor. نغيّرها بعدين.
- **سياسة الخصوصية:** في `native/privacypolicy.html`. لازم تتحدّث قبل إضافة الحسابات والمزامنة.
- **النشر على جوجل بلاي** بيحتاج حاجات إضافية: ملف AAB موقّع (مش debug) وحساب مطوّر ونموذج استخدام بيانات الصحة. دي خطوة تانية.
